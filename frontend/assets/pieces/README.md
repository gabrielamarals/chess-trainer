# Piece assets

This directory contains the complete Merida SVG chess set from the
[Lichess lila repository](https://github.com/lichess-org/lila/tree/master/public/piece/merida),
at commit `202dba26a1c0ef1f3153e44ef736258b68d33a63`.

The set was created by Armando Hernandez Marroquin and is listed by Lichess as
GPLv2+. The files are stored locally so rendering does not depend on fonts or
external URLs.
